# Pressure Reliability Console

An interactive dashboard of the T20 "Most Reliable Players Under Pressure" model (SupeRR Selector S2, Round 1).

It shows the top-10 batters and bowlers, a live weight lab that re-ranks the top 25, player drill-downs, pressure curves, how pressure is defined and validated, the win-probability model checks, and rank stability.

This is a single static `index.html` with the data embedded. It loads d3 from cdnjs.
